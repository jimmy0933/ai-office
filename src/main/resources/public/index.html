資料範圍

Token 只統計 AI Office 已收到的 usage，包含任務、會議發言、結論及成功的公司連線測試；不包含其他 App、失敗或未回報用量的呼叫。Token 與訂閱剩餘額度不能互相換算。未回報表示未知，不當成 0 用量。

Codex 透過官方 App Server 查詢帳號額度。Claude 可讀取官方 statusLine 寫出的快照；第一次需依 README 連接。Gemini 與 Antigravity 可開啟官方 CLI，再輸入 /stats model 或 /usage 查詢。公司額度需額外提供查詢 API；設定頁附格式說明。

連接你的 AI 工具

Codex、Gemini、Antigravity 與 Claude 使用各自訂閱登入。公司 LLM 使用下方獨立 HTTP 設定。

Antigravity

Gemini

Claude · 訂閱登入

會開啟官方 CLI 登入視窗，請選 Claude 訂閱帳號完成瀏覽器登入。API Key 登入會被拒絕。需另有 Claude Code 支援的訂閱方案。

Company · 公司 LLM

需與 API Base URL 同協定／主機／埠號。GET JSON 格式：{ "windows": [{ "name": "每日", "usedPercent": 20, "resetsAt": 1791590400 }] }。使用同一 Bearer Key；非 OpenAI 標準介面，請公司提供轉接。

支援 /chat/completions JSON，Base URL 可含 /v1 或完整端點。API Key 僅存在本機設定檔（未加密），不會匯出；留白保留原 Key。附加內容將送到此公司服務。

第一次使用

  1. 確認電腦有 Java 17 以上。
  2. 安裝 Codex CLI、Antigravity CLI（agy）及需要的 Gemini CLI，Codex 選 ChatGPT 登入；Gemini 選 Sign in with Google。
  3. 填入專案資料夾和 CLI 路徑，保存並檢查。
  4. 到任務看板，指派第一個任務。

此版已接上 Antigravity 官方 CLI，可派任務、提修改案及參加會議。桌面 App 登入可能與 CLI 共用帳號；若呼叫要求登入，先在終端機執行 agy 完成登入。
